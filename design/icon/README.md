# Trove icon

A 3×3×3 cube of floating glass blocks with a solid orange T in the middle slice. The T is the only light source; the glass picks up its glow and fades with distance.

Everything here is generated by `src/export.py`. Edit `src/trove_icon.py` (palettes, block gap, glow) and re-run rather than editing the outputs by hand.

```sh
pip install resvg-py pillow icnsutil
python3 design/icon/src/export.py
```

## What's here

| Folder | Contents | Used by |
|---|---|---|
| `masters/` | 1024px dark and light icons (SVG + PNG), plus the T-only `-small` versions | Source of truth for everything below |
| `macos/` | `icon-dark.icns`, `icon-light.icns`, and 1024px PNGs | `apps/desktop/assets/icon.icns` and `icon.png` are copies of the dark set |
| `icon-composer/` | Full-bleed 1024px layers per theme: `background`, `glow`, `glass`, `t` | For building a macOS 26 `.icon` file in Icon Composer (see below) |
| `mark/` | The T on its own, transparent: SVG, PNGs from 32 to 1024, `favicon.svg`, `favicon.ico` | Favicon (inlined in `packages/ui/index.html`), README, anywhere off the app tile |

## Small sizes

The `.icns` uses the T-only art for every slot shown at 16pt or 32pt (16, 32 and 64px files) and the full cube from 128px up. At 16 and 32px the glass blocks turn to noise, so they are dropped there.

## Dark and light

A `.icns` holds one appearance, so the app ships the dark version. macOS 26 can switch an icon between appearances, but only from an Icon Composer `.icon` file. electron-builder does not package `.icon` files yet (electron-userland/electron-builder#9254); Electron Packager does, alongside an `.icns` fallback for older macOS.

To make the `.icon` file when the tooling is ready:

1. Open Icon Composer (Xcode 26) and create a macOS icon.
2. Add the layers from `icon-composer/` bottom to top: `background`, `glow`, `glass`, `t`.
3. Use the `-light` files for the Default appearance and the `-dark` files for Dark.
4. Start with Liquid Glass on for the glass layer and off for the T, then adjust to taste.
